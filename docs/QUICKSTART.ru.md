# Запуск демо Workbench

Откройте [демо](https://knowledge-workbench-seven.vercel.app/) или запустите
синтетическое приложение локально:

```bash
cd prototypes/knowledge-workbench
npm ci
npm run dev
```

Приложение использует только встроенные тестовые данные. Оно не подключается к
CRM, не проверяет реальную личность пользователя и не сохраняет изменения.
Инструкции по публикации своего превью — в разделе [Vercel](VERCEL.en.md).
