# Presentations

Self-contained single-file HTML presentations of SalesWiki, generated with the
`project-showcase` skill from the repository state and **synthetic demo data**
(no production or personal data). Open directly in a browser.

- `saleswiki-showcase.html` — full project showcase: sections, card types, capabilities.
- `saleswiki-exec.html` — executive walkthrough: animated architecture diagrams, 9-role governance, autoplay demo narrative.
- `saleswiki-overview.html` — shorter project overview.

These are snapshots, not living docs: regenerate with `/showcase` when the
project state moves on, rather than editing the HTML by hand.
