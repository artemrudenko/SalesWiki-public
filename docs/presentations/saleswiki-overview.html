01

Что это даёт сотруднику

вопрос обычными словами → безопасный ответ со ссылкой

Не нужно ничего настраивать или изучать. Сотрудник задаёт вопрос в чате, а система сама проверяет, что ему можно показать, и отвечает только тем, что есть в проверенных данных. Если данных нет — честно скажет, что нет, и не придумает.

Ничего лишнего не покажет

  • Каждый видит только своё — менеджер по продажам не увидит чужих сделок, маркетинг не увидит цен и сумм
  • По умолчанию закрыто — если система сомневается, она скорее скроет, чем покажет лишнее
  • Приватные данные людей доступны только администратору
  • Без выдумок — ответ собирается из реальных карточек; нет данных — честный «не найдено»

Ничего не теряется

  • Источники хранятся как есть — звонки, письма, экспорты не переписываются
  • Любая правка — через согласование: сначала предложение, потом одобрение, и только затем применяется
  • Историю изменений видно — кто, что и когда поменял
  • Можно откатить назад, если что-то применили зря

03

Простыми словами

если встретили незнакомый термин
Карточка знаний
Одна заметка про что-то одно: компанию, сделку, звонок. Из таких карточек и состоит вся база.
Роль доступа
Кем человек работает (продажи, маркетинг, руководитель…). Роль определяет, какие карточки ему видно.
Без утечек
При любом сомнении система скорее скроет данные, чем покажет лишнее. Приватное не попадёт не в те руки.
Со ссылкой на источник
Под каждым фактом видно, откуда он взят — звонок, письмо, статья. Можно проверить, ничего не выдумано.
Согласование правок
Изменить карточку нельзя «втихую»: сначала предложение, потом одобрение, и только затем правка применяется.
Готов к демо
Систему уже можно показать: всё работает на учебных данных, проверки зелёные. Для боевого запуска нужен вход по корпоративному логину и реальные данные.
