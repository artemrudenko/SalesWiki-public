# Employee Skillset

The employee-facing skillset should stay small. Employees should not need to know implementation details.

## Core Commands

### Company Brief

`Бриф по компании <name>`

Returns fresh account context, key people, news, deals, calls, risks and next actions.

### Call Prep

`Подготовь к звонку с <company/person>`

Returns talking points, recent signals, questions, likely objections and relevant context.

### Call Analysis

`Разбери звонок <file/link>`

Returns summary, pain points, buying signals, commitments, follow-up and wiki updates.

### Lead Focus

`Покажи горячие лиды`

Returns prioritized leads with reasons and next actions.

### Deal Review

`Какие сделки под риском?`

Returns risky deals, evidence and recommended actions.

### Research Request

`Проведи ресерч по <company/topic/person>`

Runs company/news/source research and writes results back into the wiki.

### What Changed

`Что изменилось по <company/person/list> с <date>?`

Returns dated changes with sources and impact.

## Response Contract

Every employee-facing answer should include:

- short conclusion
- evidence dates
- confidence
- next action
- source links or page references
