# Managed News Resources

This list defines sources for recurring company and executive monitoring. Add sources gradually and audit monthly.

## Company-Owned Sources

| Source type | What to collect | Cadence |
| --- | --- | --- |
| Company homepage | positioning, product changes, major announcements | weekly for active accounts |
| Press/news page | official announcements | weekly |
| Blog | product, thought leadership, hiring/customer signals | weekly/monthly |
| Careers page | growth, department priorities, technology hints | biweekly |
| Investor relations | financials, leadership, risk disclosures | monthly/quarterly |

## Open Web Search

Suggested search patterns:

- `"<Company Name>" news`
- `"<Company Name>" CEO`
- `"<Company Name>" CTO`
- `"<Company Name>" funding`
- `"<Company Name>" acquisition`
- `"<Company Name>" layoffs`
- `"<Company Name>" partnership`
- `"<Company Name>" product launch`
- `"<Person Name>" "<Company Name>"`

## Source Evaluation

Before using a source heavily, create a page from `wiki/entities/sources/_template.md` and record:

- reliability
- coverage
- bias
- access/licensing constraints
- collection cadence

Follow `wiki/processes/source-governance.md` when deciding whether a source can support factual claims or only weak signals.
