# SalesWiki demo

SalesWiki explores how a shared sales and marketing knowledge base can help
people make better decisions. The public Workbench is a static demonstration
with synthetic fixture data. It does not connect to a CRM, store changes, or
provide production authentication.

**[Open the live demo](https://knowledge-workbench-seven.vercel.app/)**

## Run locally

```bash
cd prototypes/knowledge-workbench
npm ci
npm run dev
```

For Vercel setup, see [the deployment guide](docs/VERCEL.en.md). The interface
source and its local checks are in `prototypes/knowledge-workbench/`.

Для быстрого старта на русском откройте [краткую инструкцию](docs/QUICKSTART.ru.md).

Everything in this repository is for the synthetic demo. Do not add real
customer records, credentials, private notes, or unpublished articles.
