# Call Prep - Evidence-First Completeness Lens

## Decision Supported

Prepare for one concrete customer conversation without inventing the buyer's
stage, pain, authority or urgency.

## Candidate Checklist

1. Name the meeting objective from the supplied facts; if no objective is
   evidenced, state that it is missing.
2. Separate known organization/buying-process context from the question that
   still needs answering.
3. Choose only discovery questions that could change the next decision.
4. Name one preparation step grounded in a cited fact or mark it unavailable.
5. Do not turn a generic selling model into a claim about this account.

## Prompt Use

Use as a response-shape and evaluation checklist for `account-exec ×
call_prep`. It does not add retrieved facts and does not choose a sales stage.
