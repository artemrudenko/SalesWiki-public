# Wiki Layer

`wiki/` is the compiled knowledge layer. It is written for daily use by marketing and sales employees.

Each page should be:

- sourced
- dated
- linked to related entities
- explicit about confidence
- useful for action

Core files:

- `index.md` - current map of the wiki.
- `log.md` - chronological operations log.
- `entities/` - companies, people, leads, deals, calls, news, sources, and other typed cards (see `wiki/index.md`).
- `processes/` - sales/marketing operating model: research, monitoring, governance.

Engineering and implementation docs about the software itself (the permissioned MCP service architecture and demo walkthroughs) do **not** live here — they live under `docs/engineering/`. See `docs/engineering/README.md`.
