# KB Cleanup And Google Drive Ingest

Parent intake process: `ingest.md`. Sales feedback indicates that the existing Google Drive KB is useful but becoming difficult to navigate.

## Goals

- keep existing Drive as a source
- extract reusable knowledge into SalesWiki
- avoid duplicating raw documents unnecessarily
- create private cases and assets from useful documents

## Intake Classes

- sales decks
- proposals
- presales notes
- delivery/project notes
- private cases
- public case studies
- call notes
- enablement docs
- templates

## Process

1. Add Drive link or exported file reference under `raw/kb/`.
2. Record source in `tracking/processed-sources.md`.
3. Classify document type.
4. Extract reusable claims, cases, objections, use cases, assets and topics.
5. Create or update entity cards.
6. Preserve access label and sensitive data restrictions.
7. Add cleanup gaps to `tracking/coverage-gaps.md`.

## Navigation Outputs

- asset index
- private case index
- use case index
- objection index
- enablement gap report
