# Corroboration Register

Use this file to track claims supported by multiple sources.

## Evidence Strength

- `single-source` - one source only.
- `repeated-source` - repeated by related/syndicated sources; useful but weak.
- `multi-source` - confirmed by multiple independent sources.
- `primary-confirmed` - confirmed by company, event organizer, filing, transcript or direct source.
- `conflicting` - sources disagree.
