# Dedupe Register

Use this file when two or more sources appear to describe the same item.

## Duplicate Types

- `exact` - same URL after canonicalization or same file checksum.
- `syndicated` - same article republished across sites.
- `near-duplicate` - substantially same facts with minor wording changes.
- `same-event` - different pages about the same event participation, announcement or speech.
- `same-claim` - sources repeat the same claim but are not the same article.

## Decision Rules

- Exact duplicates should not create new wiki pages.
- Syndicated articles should be grouped under one canonical item.
- Near-duplicates can add evidence if they come from independent reporting.
- Repeated press-release copies do not count as strong independent confirmation.
- Independent sources confirming the same claim increase confidence.
- Contradictory sources should create a conflict note, not silent overwrite.
