# SalesWiki publication assets

This folder contains the visual kit for the public launch series. Images have
no baked-in copy so each platform can apply its own accessible title and crop.

## Canonical character

**Trace** is the SalesWiki guide: a quiet blue geometric firefly that follows
cited evidence links. It is not a chatbot or a mascot that gives advice. Use it
to represent traceability, permissioned paths and deliberate discovery.

## Files

- `trace-mascot-concept.png` — character reference for future artwork.
- `devto-01-evidence-flow.png` — why SalesWiki / evidence-to-decision story.
- `devto-02-trust-boundary.png` — permissioned reads and governed changes.
- `devto-03-safe-pilot.png` — local installation and private-pilot path.
- `devto-04-connector-paths.png` — vendor-first MCP and channel adapters.
- `linkedin-launch-hero.png` — launch post attachment.

## Guided-tour media

`tours/` contains recordings of the real synthetic Workbench, captured through
the in-product guided tour. The recordings do not contain customer data, browser
profiles or a manual cursor overlay.

- `tours/saleswiki-full-tour.gif` — compact looping preview for DEV, README or
  a social-post preview.
- `tours/saleswiki-full-tour.mp4` — full product route: role contrast, evidence,
  bounded assistant, monitoring, controlled import and review.
- `tours/saleswiki-ae-tour.mp4` — account-executive route.
- `tours/saleswiki-marketing-tour.mp4` — marketing route.
- `tours/saleswiki-curator-tour.mp4` — curator route, including review access.

Use MP4 when the platform supports video. It is much smaller and clearer than a
GIF. The GIF is a lightweight autoplay preview, not the source recording.

Use the files as source assets. Upload a platform-hosted copy before inserting
it into DEV front matter or a social post; do not rely on a local relative path.
