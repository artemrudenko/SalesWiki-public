# SalesWiki Workbench

This React/Vite interface presents synthetic account knowledge through sales,
marketing, and review workflows. It can run with in-browser fixtures or call the
local demo service. The service owns identity and access checks; the browser
never chooses a role or reads the vault directly.

Use the [repository quick start](../../docs/QUICKSTART.en.md) for both modes.
The hosted Vercel preview is browser-only and uses synthetic fixtures.
