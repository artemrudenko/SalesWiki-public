# OER Method Library — Raw Reference Register

This directory is an immutable register of externally hosted, openly licensed
sales and marketing learning sources reviewed for the SalesWiki method-library
pilot.

It does **not** mirror complete textbooks. The initial publishers expose files
for reading, but both books identify exceptions for some third-party media. The
public repository therefore preserves a dated source-and-license manifest,
canonical URL and SHA-256 of that manifest. A future full-text mirror requires
a per-asset exception audit and a separate approval.

Each accepted source has a dated manifest in this directory, a `Source - ...`
card, one processed-source row and a linked ingest run.

Methodological sources may supply a cited completeness lens, a question
checklist or a synthetic-evaluation rubric. They never establish a fact about a
company, person, customer, campaign or deal, and they never change access
policy, citation requirements or scoring weights.

Do not edit a dated manifest after collection. If the edition or license
changes, add a new dated manifest and mark the older source record superseded
or needs-review.
